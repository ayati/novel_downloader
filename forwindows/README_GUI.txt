==========================================================
  小説ePubダウンローダー  つかいかたガイド
==========================================================

■ これは何？

　小説投稿サイトの作品を、まるごと電子書籍（ePub）に変換して
　保存するアプリです。縦書きで、ルビもそのまま残ります。

　できあがったファイルは、Kindle・Kobo・スマホの読書アプリなどに
　入れて読めます。テキストファイル（.txt）も一緒に保存されます。


----------------------------------------------------------
■ はじめて起動するとき
----------------------------------------------------------

　「WindowsによってPCが保護されました」という青い画面が出ることが
　あります。これは「作った人が有料の証明書を持っていない」ために
　出るもので、ファイル自体に問題はありません。

　　1.「詳細情報」という小さな文字をクリック
　　2. 下に出てくる「実行」ボタンを押す

　毎回出るのが気になるときは、ダウンロードしたファイルを右クリック
　→「プロパティ」→ 一番下の「許可する（ブロックの解除）」に
　チェック →「OK」で、次から出なくなります。

　起動するのは novel_downloader_gui.exe です。
　同じフォルダにある novel_downloader.exe は中で使われるので、
　2つを同じ場所に置いたままにしてください。


----------------------------------------------------------
■ 基本のつかいかた（3ステップ）
----------------------------------------------------------

　1. 読みたい作品のページをブラウザで開き、URL をコピーします。

　2. アプリを起動します。
　　 コピーした URL が自動で入っていることがあります。
　　 入っていなければ、入力欄に貼り付けてください。

　3.「↓ ダウンロード」を押します。

　　 終わると「✅ 完了しました！」と出て、保存先のフォルダが開きます。
　　「📖 ePubを開く」を押せば、そのまま読書アプリで開けます。

　※ 途中でやめたいときは、同じボタンが「■ 中止」に変わります。


----------------------------------------------------------
■ 画面の見かた
----------------------------------------------------------

　上から順に、URL の入力欄、大きなボタン、進み具合、
　そして4つの「▸」で開く欄が並んでいます。

　　▸ 📄 詳細ログ  … 何が起きたかの記録（うまくいかないとき用）
　　▸ 📥 受信箱    … 出先でスマホから投げた作品の受け取り口
　　▸ 📚 本棚      … これまでに落とした作品の一覧
　　▸ 詳細設定      … 保存先・表紙・そのほかの設定

　「▸」を押すと開き、「▾」に変わります。普段は閉じたままで
　かまいません。開いた状態は次に起動したときも覚えています。


----------------------------------------------------------
■ まとめてダウンロードする
----------------------------------------------------------

　複数の作品を続けて落としたいときは、URL 欄の右の「＋」を押すと
　一覧に積まれます。積み終わったら「↓ ダウンロード」で順に処理します。

　・URL がたくさん書かれた文章を貼り付けると、全部まとめて拾います
　・1件失敗しても、残りは続けて処理します
　・「■ 中止」を押すと、そこで全体を止めます
　・終わったあと、失敗したものだけやり直すボタンが出ます


----------------------------------------------------------
■ 📥 受信箱 ― 出先でスマホから投げておく
----------------------------------------------------------

　外出先でスマホから作品を見つけたとき、その場では落とせません。
　受信箱は「あとで PC で落とす」ためのしくみです。

　【準備】
　　1. OneDrive や Google ドライブなど、スマホと PC で共有できる
　　　 フォルダをひとつ決めます。
　　2. 受信箱を開いて「フォルダを選ぶ」で、そのフォルダを指定します。

　【使いかた】
　　スマホで作品ページを開き、共有メニューから「テキストとして保存」
　　などでそのフォルダに保存しておきます。
　　URL が書いてあれば、メモ書きが混ざっていてもかまいません。

　　PC 側では、アプリが次のタイミングでそのフォルダを見に行きます。
　　　・起動したとき
　　　・5分ごと（間隔は設定で変更でき、0 にすると止まります）
　　　・アプリの窓に戻ってきたとき
　　　・「🔄 取り込む」を押したとき

　【受信箱に出るもの】
　　取り込むと、作品の題名・作者・全話数が一覧に出ます。
　　　→ 何の作品だったか思い出してから、落とすかどうか決められます。
　　短縮 URL（share.google など）も自動で開いて調べます。

　　・すでに本棚にある作品は「取得済み」と出て、二重には落としません
　　　　（その作品の話の一覧は本棚側で見られます）
　　・まだ落としていない作品は「☰」で話の一覧が見られます
　　　　一覧で行を選ぶと「ここから取得」ができます。
　　　　サイトで途中まで読んだ作品の、続きだけを落とせます。
　　・「🔗 元サイトを開く」で、ブラウザで作品ページを開けます
　　・URL が見つからないファイルは「⚠」を付けて残します（消しません）

　【取得したあと】
　　落とし終わったファイルは、同じフォルダの中の done フォルダへ
　　移動します。失敗したものは残るので、次回また出てきます。

　【自動で落とす】
　　「受信箱に入った作品を自動で取得する」にチェックを入れると、
　　見つけた作品を確認なしで落とします。既定は切ってあります。


----------------------------------------------------------
■ 📚 本棚 ― 落とした作品の管理
----------------------------------------------------------

　保存先フォルダにある作品が一覧で出ます。
　専用の管理ファイルは作らないので、フォルダを整理しても壊れません。

　【並び順】
　　「更新が新しい順」「名前順」「話数が多い順」から選べます。
　　この並び順は、次の新着チェックの確認順にもなります。

　【新着チェック】
　　「🔄 新着チェック」で、各作品にサイト側の新着があるか調べます。

　　作品数が多いと時間がかかりますが、
　　　・調べ終わった作品から順に、その行の表示が変わります
　　　・いま調べている作品が「確認中 3/47：○○」と出ます
　　　・途中で「■ 中止」を押せます（そこまでの結果は残ります）
　　既定の「更新が新しい順」なら、新着の出やすい作品から調べます。

　【続きを取得】
　　新着があった作品には「続きを取得」が出ます。
　　既存のファイルに追記し、ePub も作り直します。
　　複数あるときは「✅ 新着のある N 件をまとめて取得」でまとめて。

　【そのほか】
　　・「☰」… 手元にある話の一覧（通信しません）
　　・「📖」… その作品の ePub を開く
　　・話数の上にマウスを置くと、最後に取れている話の題が出ます
　　・「一覧を更新」… フォルダを読み直します


----------------------------------------------------------
■ 終わったときの知らせ
----------------------------------------------------------

　ダウンロードや新着チェックが終わると、次のように知らせます。

　　・ウィンドウのタイトルに結果が出ます（✅ 3 件完了 など）
　　・ほかの窓を見ているときは、タスクバーのボタンが光ります
　　　　※ 窓を見ているときは光りません
　　・受信箱が自動で落としはじめたときも知らせます

　音を鳴らすこともできます（詳細設定・既定は切ってあります）。
　Discord や Slack に飛ばすこともできます（詳細設定の Webhook）。


----------------------------------------------------------
■ 保存先と設定
----------------------------------------------------------

　【保存先】
　　ダウンロード フォルダの中の「小説」フォルダです。
　　詳細設定の「保存先」で変えられます。

　【詳細設定でできること】
　　・保存先フォルダ
　　・表紙 … おまかせ／サイトの公式表紙／自分の画像
　　・動作 … URL の自動貼り付け、完了したらフォルダを開く、
　　　　　　 受信箱を見に行く間隔、Webhook 通知、
　　　　　　 タスクバーを光らせる、音を鳴らす
　　・普段は変更不要 … 横書き、Kobo端末向け、目次の位置、
　　　　　　　　　　　 本文のフォント、取得間隔、文字コード、
　　　　　　　　　　　 挿絵を取り込まない

　【表示の言語】
　　右上で「日本語 / English」を切り替えられます。
　　作品の本文は変わりません。

　【設定の保存場所】
　　%APPDATA%\NovelDownloader\settings.json


----------------------------------------------------------
■ うまくいかないとき
----------------------------------------------------------

　「⚠ このサイトには対応していません」
　　　URL が正しいか確かめてください。
　　　対応しているサイトは「対応サイトを見る」で一覧できます。

　「⚠ 取得できませんでした（playwright の導入が必要です）」
　　　ハーメルンの作品です。このサイトだけは追加のソフトが要ります。
　　　パソコンに詳しい方向けの手順になります。

　「⚠ うまくいきませんでした」
　　　メッセージの下に、もう少し詳しい理由が出ます。
　　　　・作品が見つかりません（404）… 削除されたか URL 違い
　　　　・サイトに接続できません … ネットワークを確認
　　　　・アクセスが集中しています … 時間をおいて再度
　　　「▸ 📄 詳細ログ」を開くと、もっと詳しい記録が見られます。
　　　「📄 ログを保存」で、ファイルに書き出せます。

　うまく動かないときは、時間をおいて試すと直ることもあります。
　サイト側の作りが変わると取得できなくなることがあり、その場合は
　アプリの更新をお待ちください。


----------------------------------------------------------
■ パソコンに詳しい方へ
----------------------------------------------------------

　・本アプリは同じフォルダの novel_downloader.exe（コマンドライン版）
　　を子プロセスとして呼び出します。コマンドラインからも使えます。
　・対応サイト・全オプション・出力形式の仕様は、配布元の README を
　　参照してください。
　・ハーメルンは Cloudflare 回避のため playwright が必要です。
　　　pip install playwright
　　　python -m playwright install chromium
　・従来の watcher.bat / watcherG.bat（フォルダ監視して自動ダウンロード）
　　は今も使えますが、受信箱がその役割を引き継いでいます。
　　受信箱には「落とす前に題名と話数を確認できる」利点があります。
